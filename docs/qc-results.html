SAP QC Results

Faithfulness check of 100 generated SAPs (pair-sample-1) against their protocol PDFs, run on 25 October 2026 with the pipeline in qc-pipeline/ (design: SAP QC Pipeline). This page reports token consumption, retrieval coverage (Recall@k) and accuracy.

Read the accuracy numbers as provisional.
  • Judge not independent. The LLM judge is gpt-5.6-luna, the generator's reviewer model (plan decision D6 overridden), so it may share the reviewer's blind spots.
  • 56% of judged facts were settled by JEV alone, without a verbatim quote (D9 relaxed). Those count as correct; their error rate is not yet measured.
  • The judge has not been validated. Phase P3 (planted errors, ~100 human gold labels, thresholds for k, τ and JEV's acceptance) has not run.

1. The run

Input
  • 100 SAP / protocol pairs, all completed (100 ok, 0 failed)
  • 20,664 PDF pages (median 158 per protocol); 392 pages with no text, left unsearchable
  • 2 protocols with a garbled text layer (glyph codes) recovered page by page with image OCR
  • 10,932 SAP claims → 47,699 atomic facts (model atomizer)
Execution
  • 8 parallel workers, 16:53–19:03: 2.2 h wall clock
  • 9.7 min median per SAP, 18.5 min longest
  • 45,257 facts judged (|T ∪ R|): 25,246 by JEV, 20,011 by the LLM
  • 0 JEV failures; 396 facts queued for manual review

JEV accepted, no quote: 56% of judged factsLLM judge

JEV only ever accepts supported, so every error comes from LLM-judged facts: 2,925 errors in 20,002 LLM-judged facts (85.4% accurate). If JEV's accepted verdicts were 3% wrong, accuracy would fall by about 1.7% points.

"Not reported" facts are the weak spot

Absence facts are wrong 22.4% of the time strictly (14.4% lenient), over 2,652 judged: the SAP says an item is not reported, and the protocol reports it. In the random sample, absence facts are 77.5% accurate against 94.5% for facts that state something. Citation precision (cited pages the LLM judge said support the fact) is 21.7%.

How well the triggers find errors

The triggers put 44,173 of 47,699 facts (93%) in the flagged set, almost all of them, so accT ≈ accR. The unflagged facts that were sampled (1,084) are wrong 7.0% of the time, about as often as flagged ones: as a filter the trigger set does not yet separate risky facts from safe ones. 5. Next steps

Validate the judge (P3)
Planted errors and ~100 human gold labels, scored separately for JEV-accepted and LLM-judged facts. This is what turns these numbers into reportable ones.
Set JEV's threshold
A --jev shadow run, where the LLM judges every fact, gives the JEV-vs-LLM agreement table run_qc.py calibrate needs.
Freeze a sharper trigger set
COMPOUND and CRITICAL flag nearly everything. Trimming them before freezing (end of P2) would make accT and the miss rate informative.
